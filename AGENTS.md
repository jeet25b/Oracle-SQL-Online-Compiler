# Project collaboration preferences

- When the user says a change or setting is “OK,” treat it as approved and preserve it for this project. Do not alter or revert it in later work without the user's confirmation.
- If a new request appears to conflict with a setting the user previously approved, ask for confirmation before changing that setting.
- All new or changed pages, cards, code previews, buttons, and form controls must use the shared theme tokens for paired background and text colors. Check light and dark modes, including muted text and status labels; do not use dark fallback surfaces with inherited light-theme text. Preserve intentionally dark panels only with explicit, readable foreground colors.
- This theme requirement applies across the entire website and to every future page or object, including search fields, filters, dropdowns, menus, dialogs, tables, scrollbars, placeholders, and hover, focus, disabled, and selected states. All must match the website's selected color palette and light/dark mode; do not introduce hardcoded dark surfaces in light mode. Verify both modes whenever adding or changing UI.
- Objects of the same type must share hover and keyboard-focus behavior through common component selectors, including newly added navigation items such as Shared Code. Do not style only a hardcoded list of existing items.
- Across all existing and future pages/modules, selected/active states must be clearly distinguishable from hover states. Use a stronger theme-accent background and a persistent accent indicator (such as a left strip) for selected navigation, with a lighter accent background for hover. Preserve this distinction in light and dark themes, including when a selected item is hovered or keyboard-focused, and apply it consistently to equivalent controls.
- Hover text/tooltips must use the shared theme-aware tooltip component, including keyboard-focus labels, and match the page surface, text and accent in both themes. Do not rely on unstyled browser/OS tooltip bubbles; new dynamically created titled controls must be covered by the shared tooltip behavior.
