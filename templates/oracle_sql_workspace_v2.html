SECURE CONNECTION
Connect to Oracle
Your credentials are used to establish this session.
Need an Oracle username and password? Get FreeSQL connection details
  1. Open Oracle FreeSQL and sign in or create your own Oracle account.
  2. Open your schema’s Schema Connection Details panel (look for “Connect with…”). Copy the schema username and generate or reset a database password there if needed.
  3. Return here and enter that schema username and database password. Your Oracle website sign-in password is separate.
  4. Use the host, port and service shown by FreeSQL. For a TLS connection, enter tcps://HOST:PORT/SERVICE in Connect string. Replace the prefilled value if your schema shows different details.
  5. Select Connect to database and wait for the connected status.
Oracle’s FreeSQL connection instructions


Your Oracle password is encrypted before being stored on the server.
